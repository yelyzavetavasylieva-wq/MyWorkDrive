# Fluent System Icons

React icon components generated from **Microsoft Fluent System Icons**.

- **Source:** the [`@fluentui/svg-icons`](https://www.npmjs.com/package/@fluentui/svg-icons)
  package (the same SVGs published from the [Figma "System icons" library](https://www.figma.com/design/up0bdRfE7IP49bZ8gg2jbG/Microsoft-Fluent-system-iconography)).
- **License:** MIT — compatible with bundling into this codebase. Full notice below.
- **Generated by:** `scripts/generate-fluent-icons.mjs` (do not hand-edit the
  `*.jsx` files or `index.js`; regenerate instead).

## Usage

```jsx
import { AccessTimeIcon } from '../ui/fluent';

<AccessTimeIcon />                 // default size: 20 (most-used size in this app)
<AccessTimeIcon size={24} />       // 16 | 20 | 24 | 28 | 48
<span style={{ color: '#3388ff' }}><HomeIcon size={28} /></span>  // inherits currentColor
```

Each component renders the **hand-optimized SVG for the requested size** (Fluent
icons are not uniform scales of one path). Icons are monochrome and use
`currentColor`, so color them via CSS `color` (or the existing `icon-box`/
`icon-NN` wrapper classes).

## Scope & known caveats (this pass)

- **Regular theme only.** Filled variants were intentionally skipped.
- **Sizes 16 / 20 / 24 / 28 / 48 only.** The library also ships 32/12/10px for
  some icons; those are excluded. If a requested size is missing for an icon,
  the component renders the **nearest available size** (scaled via its viewBox)
  and exposes only the sizes it actually has.
- **Not every icon has all five sizes.** Only 564 of the ~2,900 icons define all
  five; most define a subset (see `scripts/.fluent-report.json` for the full
  per-icon breakdown). No missing size is fabricated.
- **Count:** the current MIT package contains **2,915** regular icons (2,908
  with an in-scope size + 7 orphans included at their native 32px). This is more
  than the ~2,575 estimated from the Figma snapshot — the published package is
  simply newer than that snapshot.
- **Plus 30 MyWorkDrive app icons** (`IconShares`, `IconClustering`, …),
  migrated from `src/ui/icons.jsx` and emitted with the same size-prop pattern
  but **aspect-ratio preserved** (they are often non-square). They keep their
  `IconXxx` names (no clash with the library's `XxxIcon` set) and appear in the
  same gallery. **Total exported: 2,945.** `src/ui/icons.jsx` is unchanged and
  still used by the app; the generator re-extracts from it, so re-running keeps
  the copies in sync.
